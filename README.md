## Цель работы

Изучить основы JavaScript: ввод и вывод данных, массивы, функции, условные конструкции и циклы.

## Состав проекта

- `web_lab4.html` — основная HTML-страница проекта.
- `style_lab4.css` — стили страницы.
- `script.js` — JavaScript-код лабораторной работы.
- `images/` — изображения гаджетов и аватар автора.

## Реализованные возможности

- Запрос имени пользователя с помощью `prompt()`.
- Приветствие с помощью `alert()`.
- Вывод результатов в консоль через `console.log()`.
- Массив времени автономной работы семи гаджетов.
- Функция `findMaximum()` для поиска максимального значения.
- Функция `filterLongLivers()` для фильтрации устройств, работающих больше 8 часов.
- Функция `calculateSum()` для подсчёта суммы значений.
- Цикл и условие для поиска устройств со временем работы не более 4 часов.
- Расчёт среднего времени работы и доли устройств с малым временем автономной работы.
- Условная конструкция `if...else` для проверки среднего времени работы.

## Запуск

1. Скачайте или клонируйте репозиторий.
2. Откройте файл `web_lab4.html` в браузере.
3. Введите имя в появившемся окне.
4. Посмотрите результаты в окнах сообщений и в консоли разработчика браузера.

Файл `script.js` подключён к HTML-странице с атрибутом `defer`.

## Ожидаемые результаты

Для исходного массива из семи гаджетов:

- Сумма времени автономной работы — **123 часа**.
- Среднее время автономной работы — **около 17,6 часа**.
- Максимальное значение — **36 часов**.
- Устройств со временем работы больше 8 часов — **5**.
- Устройств со временем работы не более 4 часов — **1**.
