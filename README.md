## Что реализовано по варианту 12

- Flexbox-меню навигации.
- Четыре карточки «Гаджеты недели» с названием и ключевой особенностью.
- CSS Grid «Сравнение характеристик»: процессор, экран и батарея.
- Числовые значения оформлены семантическим элементом `<data value="...">`.
- Адаптивность карточек: 4 на широком экране, 2 на планшете, 1 на телефоне.
- Адаптивность Grid: 3 колонки на широком экране, 2 на планшете, 1 на телефоне.
- Медиазапросы и ограничение переполнения по горизонтали.
- Семантические элементы `nav`, `main`, `section`, `article`, `aside`, `footer`, `dl`, `dt`, `dd`.
- Контрастные цвета, `alt` у изображения и видимый клавиатурный фокус.
