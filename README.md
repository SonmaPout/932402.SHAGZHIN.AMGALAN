# Labs2026
Учебный проект по веб-разработке

Репозиторий содержит результаты выполнения лабораторных работ по дисциплине, связанной с разработкой веб-приложений.

В проекте последовательно изучаются и применяются основные технологии создания веб-страниц: HTML, CSS, JavaScript, а также инструменты браузера для разработки и отладки.

Работы выполняются поэтапно: каждая следующая лабораторная расширяет предыдущую и добавляет новые возможности, технологии и способы организации кода.
