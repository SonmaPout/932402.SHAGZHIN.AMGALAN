## Цель работы

Научиться находить элементы DOM, изменять содержимое и стили страницы, создавать и удалять элементы, а также сохранять состояние интерфейса между перезагрузками с помощью `localStorage`.

## Состав проекта

- `web_lab5.html` — основная HTML-страница.
- `style_lab5.css` — оформление и светлая/тёмная темы.
- `script.js` — логика взаимодействия с DOM.
- `images/` — изображения из предыдущей лабораторной (сохранены в структуре ветки).

## Реализованные возможности

- Поиск элементов с помощью `getElementById()`, `querySelector()` и `querySelectorAll()`.
- Создание карточек гаджетов через `document.createElement()` и добавление через `appendChild()`.
- Формирование характеристик гаджета в виде списка `ul/li`.
- Добавление гаджета через кнопку «Добавить гаджет» с вводом названия и характеристик.
- Удаление отдельной карточки и последней карточки.
- Переключение светлой и тёмной темы через классы элемента `body`.
- Скрытие и отображение списка гаджетов.
- Проверка наличия элементов перед выполнением DOM-операций.
- Сохранение списка гаджетов, темы и состояния видимости в `localStorage`.
- Восстановление сохранённых данных и настроек после перезагрузки страницы.

## Запуск

Откройте файл `web_lab5.html` в браузере. Для проверки сохранения добавьте или удалите гаджет, измените тему, затем перезагрузите страницу.

## Соответствие критериям

Все три способа поиска DOM-элементов используются в JavaScript. Изменения выполняются без перезагрузки страницы. Добавленные карточки, выбранная тема и состояние скрытия списка сохраняются в локальном хранилище браузера.
