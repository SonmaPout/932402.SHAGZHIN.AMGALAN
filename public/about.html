О проекте

Weekly Rates — учебное приложение для демонстрации Node.js, Express и Progressive Web App.

Что реализовано

  • HTTP-сервер на Node.js и Express.
  • Раздача HTML, CSS и JavaScript из папки public.
  • Маршруты /, /about и /api/rates/:currency.
  • JSON API для USD, EUR и CNY с семью значениями курса и средним.
  • Манифест PWA и Service Worker для кеширования и офлайн-режима.

Как запустить

npm install
npm start

Откройте http://localhost:3000.
